# About

Hello, I'm Jof.

I'm a full stack software engineer and leader, currently working as cofounder/CTO on an AI startup in the process engineering space.

I first got hooked on coding in the '90s by programming my TI-85 calculator and Acorn A3000s. In 2006 I switched from mechanical engineering to software and - being the curious person I am - have worked on many different technologies including web (React since 2013, Express, Postgres, IaC etc), mobile (React Native since 2017 plus native code when required), Crypto (especially ZKPs+Ethereum) and the occassional bit of work on microcontrollers for fun.

I have a slightly strange history involving nuclear reactor inspection robots, Russian space craft, motorsport, fuel injection systems (with a few patents), fintech, healthtech and a couple of startups. You can find out more on my site below.
